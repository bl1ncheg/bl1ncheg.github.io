Репозиторий и как получить токен GitHub
  1. Откройте GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens и нажмите Generate new token.
  2. В поле Repository access выберите Only select repositories и укажите репозиторий сайта.
  3. В Repository permissions поставьте Contents: Read and write. Других прав не нужно.
  4. Создайте токен и скопируйте его. GitHub показывает токен один раз.
